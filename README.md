# Telegram-бот помощник

Личный бот: отвечает только владельцу и передаёт сообщения в Claude.
Умеет: отвечать через Claude, разбирать почту reg.ru по правилам из Google Таблицы.

## Команды
- `/start` или `/help` — подсказка
- `/ping` — проверить, что бот жив
- `/mail` — проверить почту сейчас (иначе бот проверяет её сам по расписанию)
- `/folders` — список папок ящика и какая из них используется для спама
- `/rules` — показать включённые правила и ошибки в таблице
- `/lastmail` — последние 5 писем: пометки спам-фильтра и какое правило сработало бы;
  `/lastmail спам` — последние 10 писем в папке «Спам»
- `/reset` — начать диалог с Claude заново
- любой текст — вопрос или задача для Claude

## Почта

Бот раз в `MAIL_CHECK_MINUTES` минут смотрит новые письма во «Входящих» ящика `MAIL_ADDRESS`.
Письма остаются непрочитанными. Старые письма (пришедшие до подключения) не трогаются.

Для каждого письма бот ищет первое подходящее правило в таблице (сверху вниз):

| Вкл | От кого содержит | Тема содержит | Текст содержит | Действие | Ответ | Отправлять сразу | Комментарий |
|---|---|---|---|---|---|---|---|
| да | @client.ru | | | уведомить | | | Письма клиента |
| да | | | казино; выигрыш | спам | | | Спам по словам |
| да | | прайс; цены | | ответить | Здравствуйте, {имя}! ... | нет | Запрос прайса |

- Несколько вариантов в одной ячейке — через `;`, подходит любой. Регистр не важен.
- Все заполненные условия в строке должны выполняться одновременно.
- **Действия:** `уведомить` (сообщение вам в Telegram), `спам` (перенос в папку «Спам»),
  `ответить` (ответ по шаблону), `пропустить` (ничего не делать).
- **Ответ:** можно вставлять `{имя}` (имя отправителя) и `{тема}`.
  Если «Отправлять сразу» = `нет`, черновик приходит в Telegram с кнопками
  «Отправить / Изменить / Пропустить». Если `да` — ответ уходит сразу.
- Письма, которые спам-фильтр сервера пометил в служебных заголовках (`X-Spam-Flag`,
  `X-Spam`, `X-Spam-Status`), бот переносит в «Спам» сам, даже без метки в теме.
  Исключение: письмо подошло под правило «уведомить», «ответить» или «пропустить».
  Отключить: `MAIL_SPAM_BY_HEADERS=нет` в `.env`. Порог по числу плюсов в `X-Spam-Bar`
  (заголовок фильтра reg.ru): `MAIL_SPAM_BAR_MIN=4`.
- Список перенесённых в спам писем бот присылает, только если `MAIL_SPAM_NOTIFY=да`.
  Команда `/mail` в любом случае показывает, сколько писем ушло в спам.
- Пустая таблица при первом чтении заполняется заголовками и выключенными примерами.

Если задан ключ Anthropic, письма, не подошедшие ни под одно правило, разбирает Claude:
спам переносит в «Спам», о важных пишет вам с кратким пересказом.

### Как подключить таблицу
1. Создайте пустую Google Таблицу.
2. «Настройки доступа» → добавьте адрес сервисного аккаунта (его показывает скрипт установки
   и команда `/rules`) с правами «Редактор».
3. Ссылку на таблицу впишите в `.env` как `RULES_SHEET_ID` и перезапустите бота.

## Что нужно заранее
1. Токен бота: в Telegram напишите @BotFather → `/newbot`.
2. Ваш Telegram ID: напишите боту @userinfobot, он пришлёт число.
3. Ключ API Anthropic: https://console.anthropic.com/settings/keys (на счёте должны быть средства).

## Установка на сервер (из PowerShell на Windows)

Сервер: Ubuntu/Debian, вход по SSH под root. Скрипт `deploy/install.sh` всё делает сам:
ставит пакеты, скачивает код из GitHub, создаёт Python-окружение и службу `telegram-assistant`.

1. Скачайте `deploy/install.sh` и заполненный `.env` в одну папку на компьютере, откройте там PowerShell.
2. Загрузите файлы на сервер (вместо `IP` подставьте адрес сервера):
   ```powershell
   scp .\install.sh root@IP:/root/install.sh
   scp .\.env root@IP:/root/telegram-assistant.env
   ```
3. Запустите установку:
   ```powershell
   ssh -t root@IP "sed -i 's/\r$//' /root/install.sh && bash /root/install.sh"
   ```
4. При первом запуске скрипт покажет ключ `ssh-ed25519 ...`. Добавьте его в GitHub:
   репозиторий → Settings → Deploy keys → Add deploy key (галочку «Allow write access» не ставить).
   Затем повторите команду из пункта 3.

В конце скрипт проверит, пускает ли Anthropic запросы с сервера, и покажет статус службы.
При старте бот пишет вам «Бот запущен ✅».

### Прокси
Если сервер в России, укажите в `.env` прокси `PROXY_URL=socks5://логин:пароль@адрес:порт`.
Он используется и для Telegram, и для Claude. Для Claude прокси должен быть зарубежным,
иначе Anthropic ответит ошибкой 403. Отдельные прокси: `TELEGRAM_PROXY` и `ANTHROPIC_PROXY`.

### Полезные команды на сервере
| Что сделать | Команда |
|---|---|
| Логи в реальном времени | `journalctl -u telegram-assistant -f` |
| Перезапуск после правки `.env` | `systemctl restart telegram-assistant` |
| Обновить бота до новой версии | `bash /root/install.sh` |
| Править настройки | `nano /opt/telegram-assistant/.env` |

### Запуск через Docker (необязательно)
```bash
cp .env.example .env && nano .env
docker compose up -d --build
```

## Безопасность
Файл `.env` хранит секреты и не попадает в git (он в `.gitignore`).
Сообщения от чужих пользователей бот молча игнорирует.
